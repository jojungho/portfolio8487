# JO JUNG HO — Portfolio

로컬에서 바로 실행되는 정적 포트폴리오입니다. HTML, CSS, JavaScript만 사용하며 별도 패키지 설치가 필요 없습니다.

## 로컬에서 보기

프로젝트 폴더에서 다음 명령을 실행하세요.

```powershell
.\start-preview.cmd
```

브라우저에서 `http://127.0.0.1:4173/`을 열면 됩니다. `start-preview.cmd`를 더블클릭해도 실행됩니다. 이 컴퓨터에서는 Codex에 포함된 Node.js를 자동으로 찾아 사용합니다. 다른 컴퓨터에서는 Node.js를 설치한 뒤 같은 파일을 실행하면 됩니다.

서버를 종료하려면 실행 창에서 `Ctrl+C`를 누르세요. 다른 포트가 필요하면 `.\start-preview.cmd 4174`처럼 번호를 붙이면 됩니다. 외부 네트워크에서는 접근할 수 없는 로컬 미리보기입니다.

## 영상 관리

로컬 서버를 실행한 뒤 `http://127.0.0.1:4173/admin/`을 여세요.

1. **+ 영상 추가**를 누르고 영상 종류를 고릅니다.
2. YouTube 링크는 주소를 넣으면 제목과 채널을 자동으로 가져옵니다. MP4는 파일을 `assets/videos/`에 먼저 복사한 뒤 `assets/videos/파일명.mp4` 경로를 입력합니다. 선택으로 `assets/` 안의 PNG, JPG, WebP 표지 이미지를 지정할 수 있습니다.
3. 카테고리, 작품 제목, 설명, 담당 작업을 입력하고 **영상 저장**을 누릅니다. **WORKS 분류**에서 ShowReel 또는 Rigging을 선택하면 CINEMATIC&VFX 페이지의 **ALL / ShowReel / Rigging** 필터에 반영됩니다. 기존 등록 영상은 기본적으로 ShowReel에 표시됩니다.
4. 해당 카테고리 WORKS에 16:9 썸네일이 추가되고, 음소거 미리보기와 상세 페이지가 연결됩니다.

목록의 **수정**, **삭제**, 휴지통의 **복원**으로 관리합니다. 삭제는 휴지통 이동이며 실제 영상은 유튜브에 그대로 있습니다. 등록 정보는 `data/videos.json`에 저장되고, 변경 전 파일은 `.backups/`에 남습니다. 브라우저를 닫거나 서버를 다시 실행해도 내용이 유지됩니다. 관리 API는 로컬 서버에서만 실행합니다.

유튜브의 공개 범위는 **일부 공개** 또는 **공개**, **삽입 허용**을 사용하세요. 비공개 영상은 일반 방문자가 볼 수 없습니다. MP4 작품은 목록에 영상 프레임이 표시되고, 마우스를 올리면 무음 미리보기가 재생되며, 상세 페이지에서는 재생 컨트롤이 제공됩니다.

### WORKS 분류 추가

영상 **추가 / 수정 → WORKS 분류 → ＋ 분류 추가**에서 이름을 입력하고 **추가**를 누릅니다. 새 분류가 선택되면 **변경 저장**으로 영상에 적용합니다. 분류는 추가 즉시 파일에 저장되며 영상 수정을 취소해도 유지됩니다. 같은 이름은 중복으로 추가할 수 없습니다.

CINEMATIC&VFX 페이지의 **ALL / ShowReel / Rigging** 옆에 새 분류 필터가 자동으로 생깁니다. 분류 정보는 `data/videos.json`의 `workTypes`에 저장되어 재실행·공개 사이트 내보내기에도 유지됩니다. FEATURED 카드 구성과는 별개입니다.

### 1단 배경 영상 연결

영상 **추가 / 수정 → 1단 영상 연결**에서 **1 (VIDEO 01)** 또는 **2 (VIDEO 02)**를 체크하고 저장합니다. 두 번호에 같은 영상을 연결할 수도 있습니다. 같은 번호를 다른 영상에 지정하면 기존 연결은 자동으로 해제됩니다. 각 번호의 체크를 해제하거나 연결된 영상을 휴지통으로 보내면 해당 번호는 기존 MP4 테스트 영상으로 돌아갑니다. 휴지통에서 복원한 영상은 다시 체크해서 연결합니다.

연결 정보는 영상 목록과 함께 파일에 저장되며 공개 사이트 내보내기에도 포함됩니다. 첫 화면에서는 선택한 유튜브 영상을 음소거로 반복 재생합니다. 삽입 제한, 연결 실패 또는 자동 재생 차단 시 썸네일을 표시하며 VIDEO 버튼으로 재시도할 수 있습니다. 모션 줄이기 설정에서는 버튼을 직접 눌러 재생합니다.

### 영상 순서 변경

1. 관리 화면에서 필요한 카테고리를 선택하고 **순서 변경**을 누릅니다. 모든 카테고리를 한꺼번에 정렬할 수도 있습니다. 순서 변경을 시작하면 제목 검색은 해제됩니다.
2. 영상 카드 아래 **드래그** 손잡이를 원하는 위치로 끌거나 **앞으로 / 뒤로** 버튼을 누릅니다. 왼쪽에서 오른쪽, 위에서 아래가 표시 순서입니다.
3. **순서 저장**을 누르면 파일에 저장되고 해당 카테고리의 홈페이지 영상 목록에도 반영됩니다. **취소**를 누르면 저장 전 순서로 돌아갑니다. 영상이 2개 이상이어야 순서를 바꿀 수 있습니다.

정렬은 등록된 영상에 적용됩니다. 카테고리별 정렬은 다른 카테고리와 휴지통의 순서를 유지합니다. 새로 추가하는 영상은 기존처럼 맨 앞에 배치됩니다. 배포한 사이트에는 다시 내보내고 배포해야 반영됩니다.

## 프로필 · 경력 편집

PROFILE 페이지 오른쪽 위 **프로필 편집** 또는 `http://127.0.0.1:4173/admin/profile.html`에서 편집합니다. 영상 관리 화면에서도 **프로필 편집**으로 이동할 수 있습니다.

1. 회사를 선택해 회사명, 지역, 부서, 재직 기간, 담당 분야, 직책, 업무 내용을 수정합니다. **경력 추가**와 **위로 / 아래로**로 경력을 추가하거나 순서를 바꿀 수 있습니다.
2. **이미지 추가**에서 JPG, PNG, WebP 파일을 여러 장 선택할 수 있습니다. 파일당 10MB 이하이며, 파일은 이 프로젝트의 `assets/profile/uploads/`에 복사됩니다.
3. 각 이미지 아래 **중앙 흰색 타이틀**을 수정합니다. 이미지에 마우스를 올려 어두운 배경과 타이틀을 미리 볼 수 있습니다. **교체 / 삭제 / ← / →**로 이미지와 순서를 관리합니다.
4. **변경 저장**을 누르면 로컬 홈페이지에 반영됩니다. 저장 전에는 **새로 불러오기**로 편집을 취소할 수 있습니다. 이미지 삭제는 프로필 목록에서 제외하는 동작이며 원본 파일은 남습니다.

프로필 내용은 `data/profile.json`, 저장 전 내용은 `.backups/profile-*.json`에 보관됩니다. 다른 창의 변경과 충돌하면 덮어쓰지 않고 오류를 표시합니다. 공개 사이트 내보내기에는 저장된 프로필과 첨부 이미지가 포함되며, 공개 사이트에 반영하려면 다시 배포해야 합니다. 편집 화면과 API는 로컬에서만 사용합니다.

## 포트폴리오 화면 구성

03~06 카테고리는 현재 잠금 상태입니다. 기존 테스트 콘텐츠는 페이지에서 제거했고, 메뉴에는 번호와 자물쇠만 표시합니다. 직접 주소로 들어가도 잠금 안내만 나옵니다. 영상 관리에서도 해당 카테고리를 선택하거나 저장할 수 없습니다. WORKS의 ShowReel / Rigging 및 사용자 추가 분류와는 별개입니다.

나중에 다시 사용할 때는 `content-model.mjs`의 해당 카테고리 `locked`를 해제하고, `projects/`의 잠금 페이지를 새 콘텐츠로 교체한 다음 `projects/creature-rigging.html`의 해당 메뉴와 이전 카테고리 링크를 복구합니다. 로컬 서버를 재시작하면 관리 화면에서도 사용할 수 있습니다.

- **1단 PORTFOLIO**: 화면을 채우는 배경, JO JUNG HO 타이틀과 직함. 하단 중앙의 **01 / 02** 버튼으로 두 배경 영상을 선택합니다. 선택한 버튼이 밝게 표시되며, 영상이 준비되면 부드럽게 전환됩니다.
- **2단 FEATURED**: 검정 여백 가운데 좁은 세로 카드 6개를 붙여 배치합니다. 각 카드에는 가운데 정렬한 흰색 타이틀과 테두리가 있는 `View more` 버튼이 표시됩니다. 마우스를 올리면 이미지, 타이틀, 버튼을 포함한 카드 전체가 약 6% 커지며 주변 카드 위로 올라옵니다. 카드 안에서 마우스를 좌우로 움직이면 해당 방향으로 최대 15도까지 부드럽게 기울어져 입체감을 줍니다. 마우스가 벗어나면 원래 크기와 각도로 돌아옵니다. 터치 기기와 모션 줄이기 설정에서는 기울기 효과를 생략합니다.
- 카드를 클릭하면 `projects/`의 해당 상세 페이지로 이동합니다. 각 페이지는 배경 이미지와 타이틀, 카테고리 메뉴, 소개, 가로 갤러리, WORKS 순서로 구성했습니다.
- 태블릿과 모바일에서는 2단 이미지를 가로로 스크롤할 수 있습니다.

## 이미지와 영상 바꾸기

PROFILE은 `data/profile.json`에 이름과 경력·작품 이미지 정보를 담고, `profile.css`로 디자인합니다. 내용은 **프로필 편집**에서 관리합니다. `projects/cloth-simulation.html`은 기본 화면이며, 공개 사이트 내보내기 시 저장한 최신 경력으로 갱신됩니다.

현재 이미지는 AI로 만든 **레이아웃 확인용 테스트 이미지**입니다. 실제 참여작이나 경력을 표시한 것이 아닙니다.

`assets/projects/`의 파일을 같은 이름으로 교체하면 메인 카드와 상세 페이지에 함께 반영됩니다.

| 파일 | 카테고리 |
| --- | --- |
| `creature-rigging.png` | CINEMATIC&VFX |
| `cloth-simulation.png` | PROFILE |
| `character-work.png` | 제목 공백 |
| `destruction-fx.png` | 제목 공백 |
| `fluid-effects.png` | 제목 공백 |
| `procedural-rd.png` | 제목 공백 |

기존 링크와 이미지 연결을 유지하기 위해 파일명은 그대로 사용합니다.

생성 도구와 프롬프트는 `assets/projects/PROMPTS.md`에 기록했습니다. 타이틀은 이미지에 합성하지 않고 HTML 글자로 넣어 자유롭게 수정할 수 있습니다.

첫 화면에는 느린 카메라 움직임을 적용한 두 테스트 영상을 연결했습니다. **01**은 성 배경 `assets/videos/hero-reel.mp4`, **02**는 크리처 배경 `assets/videos/hero-reel-02.mp4`입니다. 선택한 영상이 화면을 가득 채우며 무음으로 반복 재생됩니다. 현재 타이틀은 왼쪽 상단에 겹쳐 표시됩니다. 두 번째 영상은 처음 선택할 때 불러오며, 다른 영상과 화면 밖의 영상은 일시 정지합니다.

**실제 포트폴리오 영상을 연결할 때:** 관리 화면에서 YouTube 또는 MP4 영상을 추가·수정하고 **1단 영상 연결** 체크박스로 지정하세요. 연결하지 않은 번호는 로컬 MP4 테스트 영상을 사용합니다. 로컬 MP4 자체를 교체하려면 01은 `assets/videos/hero-reel.mp4`, 02는 `assets/videos/hero-reel-02.mp4`를 교체하면 됩니다. 타이틀은 홈페이지에서 얹으므로 영상에 이름을 넣을 필요는 없습니다.

영상이 없거나 브라우저에서 재생을 허용하지 않으면 선택한 영상의 포스터 이미지를 보여줍니다. 01의 포스터는 `assets/hero-concept.png`, 02는 `assets/projects/creature-rigging.png`입니다. 모션 줄이기 설정에서는 처음에 포스터를 표시하며, 사용자가 01 / 02 버튼을 직접 누르면 선택한 영상을 재생합니다. 상세 페이지는 현재 테스트 이미지로 구성되어 있습니다. 테스트 영상 제작 정보는 `assets/videos/README.md`에 있습니다.

## 배포 준비

공개 홈페이지는 정적 파일로 동작합니다. `node scripts/export-site.mjs`를 실행하면 `exports/portfolio-날짜/`에 배포 파일이 만들어집니다. 이 폴더에는 공개 홈페이지와 등록 데이터만 포함되며, 관리 화면·로컬 서버·백업·휴지통 작품은 제외됩니다. 이 폴더를 Cloudflare Pages에 올리면 됩니다. 이번 작업에서는 내보내기나 게시를 실행하지 않았습니다.

공개 후 영상 정보를 바꿀 때도 로컬 관리 화면에서 저장하고, 내보내기 후 다시 배포합니다. 공개 서버에서 직접 수정하는 온라인 관리자 기능은 이번 로컬 관리 화면에 포함되지 않습니다.
